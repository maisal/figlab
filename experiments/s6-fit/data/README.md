# NIST StRD nonlinear regression data

These 27 files are the nonlinear regression problems of the NIST Statistical
Reference Datasets (StRD), unchanged.

- Source: https://www.itl.nist.gov/div898/strd/nls/nls_main.shtml
  (files from https://www.itl.nist.gov/div898/strd/nls/data/LINKS/DATA/)
- Downloaded on 2026-10-14 by `scripts/download-nist.sh`.
- License: public domain. They are a work of the US government (NIST).

Each file has the model, two starting points, the certified parameter values
and standard deviations, the certified residual sum of squares, and the data.
The certified values have 11 significant digits.
