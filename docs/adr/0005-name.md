# 0005. Name the project figlab

- Status: Accepted
- Date: 2026-10-09

## Context

The project needs one name for the app, the repository, the command-line tool, and the file formats.

## Decision

The name is figlab. It is written in lower case.

| Use | Name |
|---|---|
| App and repository | figlab |
| Command-line tool | `figlab` |
| Project folder | `*.figlab` |
| Bundled project (zip) | `*.figz` |
| Command files | `*.figc` |
| User function files | `*.figf` |

## Reasons

- It says what the tool is for: making figures from lab data.
- It is short and easy to type as a command name.
- The file extensions share the prefix `fig`, so figlab files are easy to recognize.

## Consequences

- The extensions are listed in language.md Section 11 and spec.md Section 11.
